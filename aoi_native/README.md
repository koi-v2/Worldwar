# Koi World — Native Android Prototype

This is a Godot 4 project for a native 2D top-down social-avatar game. It is **not a WebView app**.

## Current prototype
- Top-down town map drawn by Godot.
- Player avatar movement using keyboard or on-screen directional buttons.
- A few decorative buildings, trees, and NPC placeholders.
- Offline prototype only; online multiplayer, accounts, saving, character customization, and activities are not implemented yet.

## Android APK
The workflow `.github/workflows/aoi-android.yml` exports a debug APK and uploads it as the `KoiWorld-Android-APK` artifact. Open the repository's Actions tab, choose **Build Koi World Android APK**, run the workflow, then download the artifact from a successful run.

Package ID: `com.koiv2.koiworld`
