Pixel Adventure

Jelajahi platform, lompat, dan ayunkan pedang. Unggah character sheet untuk mengganti karakter demo dengan spritesheet milikmu.

Game Dijeda

Tekan lanjut untuk kembali bermain.

Cara pakai spritesheet: unggah gambar PNG/JPG, isi lebar dan tinggi satu frame dalam piksel, lalu tekan Pakai spritesheet. Frame dibaca berurutan dari kiri ke kanan dan atas ke bawah. Jika sheet berisi banyak baris animasi, pilih baris yang sesuai di pengaturan lanjutan browser console belum diperlukan; saat ini satu baris frame dipakai untuk animasi gerak dasar. Sprite otomatis dipotong berdasarkan ukuran frame.

Kontrol keyboard: ← / A kiri · → / D kanan · Spasi / ↑ / W lompat · J / X serang · Esc jeda.
Kontrol HP: gunakan tombol di bawah layar. Sentuh tombol untuk bergerak, lompat, atau menyerang.
