# GrowWorld — Godot prototype

This is the native Godot 4 project for the Growtopia-inspired Android game. It is not a WebView project.

## Current prototype
- 2D block world with grass, dirt and stone
- Character movement, gravity, collision and jump
- Touch controls and keyboard fallback
- Tap a nearby block to mine it
- Basic inventory counters and hotbar selection
- Procedural placeholder graphics to establish gameplay

## Open
Open the `growtopia/` directory in Godot 4.3 or newer and run `scenes/world.tscn`.

## Important
This is an early gameplay prototype. Character sprite sheets, polished art assets, world saving, block placement, and multiplayer are not implemented yet. Android APK export needs Godot's Android export templates and Android SDK configuration.
